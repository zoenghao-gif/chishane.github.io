# 本地运行清单

## 启动

1. 安装 Node.js 22.5 或更高版本。
2. 执行 `pnpm install`。
3. 执行 `pnpm dev`。
4. 访问 `http://127.0.0.1:5173`。

## 数据库

- SQLite 文件自动生成于 `data/what-to-eat.sqlite`。
- 匿名设备身份通过 HttpOnly Cookie 保存。
- 清除 Cookie 会创建新的本地匿名用户。
- 账户删除会删除该匿名用户的全部记录和设置。

## 生产预览

1. 执行 `pnpm build`。
2. 执行 `pnpm start`。
3. 访问 `http://127.0.0.1:8787`。

## 上线门槛

- 单元测试和构建全部通过。
- 两个浏览器设备的 Cookie 数据隔离测试通过。
- 删除账户可同时删除认证用户、记录和设置。
- 隐私政策和用户协议已替换占位内容。
